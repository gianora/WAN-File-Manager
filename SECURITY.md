# Security Policy

## Supported Versions

Only the latest release branch receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We appreciate responsible disclosure from security researchers and the open-source community. If you discover a security vulnerability in WAN File Manager, please report it privately rather than creating a public issue.

### Preferred Reporting Method

Please report vulnerabilities using **GitHub Private Vulnerability Reporting**:
1. Navigate to the [Security Advisories tab](https://github.com/gianora/WAN-File-Manager/security/advisories).
2. Click **Report a vulnerability** to open a confidential advisory draft.
3. Include details such as:
   - Affected endpoints or files
   - Vulnerability type and severity (e.g., CWE ID)
   - Steps to reproduce or proof of concept (PoC)
   - Suggested remediation (if available)

### Alternative Method

If GitHub Private Vulnerability Reporting is unavailable, you may contact the maintainer directly via email or through the contact channels listed on the maintainer's GitHub profile (`gianora`).

### What to Expect

- **Acknowledgment**: We aim to acknowledge receipt of your report within 48 hours.
- **Coordination**: We will review the vulnerability, prepare a fix in a private branch, and verify the remediation with you.
- **Disclosure & Credit**: We follow coordinated vulnerability disclosure guidelines (typically up to 90 days). Once the fix is published, we will publish the security advisory and properly credit you as the reporter.
